## Why it exists

CSV is the format everyone actually exchanges, and reading one in a text editor means counting commas. Opening it in a spreadsheet means leaving your editor — and often means the spreadsheet silently reformats your data on the way back out: dates rewritten, leading zeros dropped, long identifiers turned into scientific notation.

This extension puts the grid **inside VS Code, on top of the file itself**. The text document stays the source of truth, so `Ctrl+S`, `Ctrl+Z`, the dirty indicator, file watching and Git all behave exactly as they do for any other file. Nothing is cached in a parallel model that can drift, and nothing reformats your data behind your back.

## What it does

<div class="feature-grid not-content">
  <div class="feature-card">
    <span class="eyebrow">Edit</span>
    <h3>A real grid over a real file</h3>
    <p>Double-click, <code>F2</code>, or just start typing. Insert, duplicate, move, delete and hide rows and columns. Split a column, merge several, transpose the table, fill down and right, trim, change case, drop duplicates. <code>Ctrl+S</code> saves the file; <code>Ctrl+Z</code> undoes into VS Code's own undo stack.</p>
  </div>
  <div class="feature-card">
    <span class="eyebrow">Find</span>
    <h3>Excel-style AutoFilter</h3>
    <p>A searchable list of each column's distinct values with counts, tri-state <code>(Select All)</code> and <code>(Blanks)</code>, plus Text, Number and Date condition filters with wildcards. Value lists cascade from the other columns, so you never pick a combination that matches nothing.</p>
  </div>
  <div class="feature-card">
    <span class="eyebrow">Understand</span>
    <h3>Statistics and charts</h3>
    <p>Per-column counts, distinct values, blanks, min, max, sum, mean, median, standard deviation, quartiles and top values. Histograms for numeric columns, top-value bars for everything else.</p>
  </div>
  <div class="feature-card">
    <span class="eyebrow">Query</span>
    <h3>Real SQL, in memory</h3>
    <p>The file is loaded into an in-memory SQLite database named <code>csv</code>. Joins onto itself, window functions, aggregates — all of it. Results copy out or open as a new CSV.</p>
  </div>
  <div class="feature-card">
    <span class="eyebrow">Repeat</span>
    <h3>Pipelines</h3>
    <p>Describe a cleanup once as a <code>.csvpipe.json</code> file and re-run it on demand, on open, or on save. Fifteen no-code steps, two low-code expression steps, and code steps that shell out to pandas, jq, awk, Miller or anything else you already have.</p>
  </div>
  <div class="feature-card">
    <span class="eyebrow">Ship</span>
    <h3>Export anywhere</h3>
    <p>The whole file or just the selection, to JSON, Markdown, HTML, SQL inserts, or a different delimiter. Selections go straight to the clipboard in a form Excel understands.</p>
  </div>
</div>

## Sixty seconds to useful

<Steps>

1. **Install the extension.**

   From the Marketplace, or from a terminal:

   <Tabs syncKey="install">
     <TabItem label="VS Code">
       ```bash
       code --install-extension bash-365.csv-grid-viewer
       ```
     </TabItem>
     <TabItem label="VSCodium / Open VSX">
       ```bash
       codium --install-extension bash-365.csv-grid-viewer
       ```
     </TabItem>
     <TabItem label="From a .vsix">
       ```bash
       code --install-extension csv-grid-editor-1.0.0.vsix
       ```
     </TabItem>
   </Tabs>

2. **Open any delimited file**, then choose **Open in Grid Editor** from the title bar, Explorer menu, or Command Palette. CSV/TSV open as text by default so the grid does not hijack them.

3. **Select a range of numbers.** The status bar shows count, sum, average, minimum and maximum, exactly like the spreadsheet you came from.

4. **Click the caret in a column header** (or press `Alt+Down`) for sorting and Excel-style filtering.

5. **Open the SQL panel** and run `SELECT * FROM csv LIMIT 10`.

</Steps>

<Aside type="tip" title="Want the grid every time?">
  Use **Open With…** → **CSV Editor** → **Configure default editor…**, or set `"workbench.editorAssociations": { "*.csv": "csv.gridEditor" }` (and the same for `.tsv` / `.tab` / `.psv`) in your settings.
</Aside>
